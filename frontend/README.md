# 人物监控前端

原生HTML/CSS/JavaScript组件，无需npm构建，由后端在/monitor/提供静态资源。用户模式包含动态、分析、问答、原文检索及提醒；运维模式仅供可信开发环境诊断。

## 集成约定

- 同源代理API与静态资源，避免将私有凭证发往其他来源。
- chat-api.js提供私有传输，用户身份来自服务端验证的映射。
- 模型密钥保留在后端，前端仅处理模块用户凭证。
- 正文和模型输出按文本渲染，引用绑定保存版本及Unicode字符偏移。
- 卸载组件时关闭SSE和定时器，取消过期请求，避免旧结果覆盖新会话。
- research模式隐藏运维入口；production环境同时在服务端执行权限限制。

具体路径、错误处理和身份协议见[API与身份集成](../INTEGRATION.md)，运行要求见[部署说明](../DEPLOYMENT.md)。当前总平台身份映射与远程部署尚未接通。
